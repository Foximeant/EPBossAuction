**EP Boss Auction** — аддон для World of Warcraft (Sirus 3.3.5+), предназначенный для проведения аукционов на основе EPGP прямо в рейде. Игроки делают ставки EP на предметы с боссов, а лутер управляет процессом, просматривает текущие ставки и синхронизирует данные с рейдом.

## ✨ Особенности

- 📋 **Таблица предметов** по каждому боссу с отображением топ‑N ставок (настраивается).
- 📝 **Журнал ставок** — полная история всех ставок с указанием времени, игрока, суммы, предмета и босса (до 2000 записей).
- 🔒 **Блокировка ставок** — лутер может временно запретить приём ставок, состояние видно всем.
- 🟡 **Офф‑спек ставки** — отметка `(O)` в таблице и журнале, отдельный коэффициент (настраивается лутером).
- 🪙 **Очередь на токены Т6** — окно с многострочным текстом для ведения очереди на токены (сохраняется и синхронизируется с рейдом).
- 🖱️ **Кнопка у миникарты** — перетаскиваемая, с сохранением позиции, отображает статус лутера.
- ⚙️ **Полноценное окно настроек** (4 вкладки) — гибкая кастомизация внешнего вида.
- 📡 **Синхронизация данных** между лутером и участниками рейда через аддон‑канал.
- 🔗 **Интеграция с EPGP** — автоматическое получение EP игрока, учёт твинков.
- 🎨 **Поддержка ElvUI** — главное окно, журнал и окно очереди стилизуются под ElvUI.
- 🚀 **Оптимизация производительности** — исправлены утечки памяти, добавлено кэширование классов и единый менеджер таймеров.

## 🆕 Что нового в версии 1.6.x

### 🔧 Критические исправления
- **Устранена утечка фреймов** при обновлении таблицы — старые строки теперь полностью удаляются, что исключает зависания интерфейса.
- **Исправлена ошибка `SetParent` для текстур** при удалении строк.
- **Восстановлена работа выпадающего списка предметов** после оптимизации.

### ⚡ Улучшения производительности
- **Единый менеджер таймеров** — вместо создания множества временных фреймов используется один с таблицей активных таймеров.
- **Кэширование классов игроков** — цвета классов запоминаются при обновлении рейда, снижая нагрузку на отрисовку.
- **Защита от рекурсии в `RefreshTable`**.
- **Разбиение обработчика сообщений** — каждая команда обрабатывается отдельной функцией.

### ✨ Новые возможности
- **Очередь на токены Т6** — новая кнопка «Очередь» открывает окно с многострочным текстовым полем. Лутер может редактировать очередь и рассылать её рейду. Текст сохраняется между сессиями.
- **Настройка коэффициента офф‑спек** — лутер может изменить множитель через слайдер в настройках или командой `/epbaoffspec <0.1-1.0>`.
- **Увеличен лимит журнала ставок** до 2000 записей.

### 🛠️ Прочие улучшения
- Таймеры изменения размера окна и обновления EP переведены на новый менеджер.
- Оптимизировано обновление EP — уменьшено количество вызовов.
- Добавлен сброс кэша EP и классов при смене рейда.

## 📋 Требования

- World of Warcraft 3.3.5 (Wrath of the Lich King)
- Установленный EPGP‑аддон (любой из: EPGP, EPGP_Auction, CEPGP, EPGPCore)
- (Опционально) ElvUI для применения скинов

## 📥 Установка

1. Скачайте последнюю версию из [релизов](https://github.com/Foximeant/EPBossAuction/releases).
2. Распакуйте архив в папку `World of Warcraft\Interface\AddOns\`.
3. Убедитесь, что папка называется `EPBossAuction`.
4. Запустите игру и включите аддон в списке аддонов.

## 🎮 Использование

### Основные команды

| Команда                    | Действие                                         |
|----------------------------|--------------------------------------------------|
| `/epba`                    | Открыть/закрыть главное окно                     |
| `/epbaoptions`             | Открыть окно настроек                            |
| `/epbaupdate`              | Принудительно обновить свой EP                   |
| `/epbasave`                | Принудительно сохранить данные                   |
| `/epgpfind`                | Поиск EPGP‑аддона (для отладки)                  |
| `/epbazoom+ / - / reset`   | Увеличить / уменьшить / сбросить масштаб окна    |
| `/epbaoffspec <0.1-1.0>`   | Установить коэффициент офф‑спек (только лутер)   |

### Интерфейс

- **Выбор босса** — выпадающий список слева вверху.
- **Блокировка ставок** — чекбокс «Блок» (доступен только лутеру). При включении ставки не принимаются, кнопка «Сделать ставку» блокируется у всех.
- **Офф‑спек** — чекбокс «Офф‑спек». При включении ставка отмечается `(O)` и применяется понижающий коэффициент.
- **Таблица предметов** — для выбранного босса отображается список предметов. Названия предметов окрашены в золотой или по редкости (настраивается). Во второй колонке — топ‑N ставок.
- **Поле ввода ставки** — введите сумму (целое число) и нажмите Enter или кнопку «Сделать ставку». Если сумма превышает ваш EP (с учётом офф‑спека), текст становится красным.
- **Кнопка «Запросить»** — для не‑лутера: запросить актуальные данные у лутера.
- **Кнопка «Очистить таблицу»** — (только лутер) завершает аукцион, удаляя все ставки для текущего босса.
- **Кнопка «Журнал»** — открывает окно с историей всех ставок.
- **Кнопка «Очередь»** — открывает окно очереди на токены Т6.

### Окно очереди на токены Т6

- Доступно всем, но редактировать может только лутер.
- Текст автоматически сохраняется и рассылается рейду при нажатии «Сохранить».
- Кнопка «Очистить» удаляет текст (только для лутера).

### Кнопка миникарты

- Перетаскиваемая иконка у миникарты. Клик — открыть/закрыть главное окно.
- При наведении показывает статус лутера.
- Позиция, размер и видимость настраиваются.

### Журнал ставок

- Открывается кнопкой «Журнал» в главном окне.
- Показывает историю всех ставок с указанием времени, игрока, суммы, предмета и босса.
- Офф‑спек ставки отмечены `(O)`.
- Окно можно растягивать, текст автоматически переносится.
- Только лутер может очищать журнал.

## ⚙️ Настройки

Окно настроек (вызывается через `/epbaoptions` или кнопку ⚙ в главном окне) содержит четыре вкладки:

### Общие
- Режим отладки (вывод в чат отладочной информации).
- Минимальная ставка (фиксирована, задаётся в коде).
- Автоматически запрашивать данные при входе в рейд.
- Подтверждать ставки (диалог подтверждения).
- Включить звук при перебитии ставки (файл задаётся в настройках).
- **Коэффициент офф‑спек** — слайдер от 10% до 100% (только для лутера).

### Таблица
- Размер шрифта названий предметов и ставок.
- Ширина колонок.
- Количество отображаемых ставок (1–5).
- Цвета строк (чётные, нечётные, выделенная, при наведении).
- Режим цвета названий предметов (золотой / по редкости).
- Высота строки (пиксели).
- **Привязка тултипа** при наведении на строку (у курсора, справа, слева, сверху, снизу и т.д.).

### Миникарта
- Показывать кнопку у миникарты.
- Размер кнопки (20–40 пикс).
- Радиус от центра (50–100 пикс).
- Кнопка «Сбросить позицию» (возвращает на 3 часа).

### Окно
- Прозрачность окна (30–100%).
- Масштаб окна (кнопки +, –, 100%).
- Блокировка окна (запретить перемещение).
- Кнопки «Сбросить позицию окна» и «Сбросить размер».

## 🛠️ Для разработчиков

Аддон написан на Lua с использованием стандартного API WoW 3.3.5. Основные модули:

- `core.lua` — инициализация, утилиты, управление данными, менеджер таймеров.
- `ui.lua` — создание и управление главным окном, таблицей ставок, окном очереди.
- `comm.lua` — сетевое взаимодействие, обработка сообщений.
- `epgp.lua` — интеграция с EPGP, получение EP игроков.
- `events.lua` — обработка событий (вход в мир, обновление рейда, сообщения аддонов).
- `journal.lua` — окно журнала ставок.
- `options.lua` — панель настроек.
- `minimap.lua` — кнопка у миникарты.

При внесении изменений рекомендуется отключать режим отладки (`debug = false`) в настройках или коде для production.
